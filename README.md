Proyecto formativo de Ingeniería en Desarrollo y Gestión de Software - UTCAM.

## Estructura del Repositorio
- `.github/workflows/`: Flujos de trabajo automatizados (CI/CD).
- `docs/`: Documentación técnica, configuraciones, casos de prueba y estrategia de despliegue.
- `src/`: Directorio preparado para el código fuente del aplicativo.
- `tests/`: Pruebas unitarias e integrales del sistema.

## Ramas Principales
- `main`: Código en estado productivo.
- `develop`: Integración continua de características.
